How to read this

  • Only people who said yes to anonymous stats are counted, so real usage is higher.
  • Each opted-in install is counted at most once per UTC day, with no ID, so counts can't be linked to anyone.
  • "First counted" includes existing users who have just opted in, not only new installs.
  • Weeks start on Monday. Numbers refresh every few minutes. Raw data: /stats (JSON).
